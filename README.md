# Abhay Gupta — Futuristic Research Portfolio

AMOLED-black, interactive personal portfolio for Abhay Gupta, Research Scientist — Analytical R&D.

## Current build

- Pure AMOLED black visual system
- Responsive single-page portfolio
- Interactive particle/molecular background
- Scientific-console hero visual
- VIATRIS + Endo experience timeline
- Interactive Scientific Arsenal with instrument diagrams and detail modals
- HPLC, UPLC, IR/FTIR, UV-Vis, DSC, Ion Chromatography, LCMS, ICP-MS, Zeta Sizer, pH Meter, Osmometer and GC
- CBG × CBD HPLC research case study
- Publication, education and contact sections
- No external JS framework or paid dependency

## Content basis

Professional information is based on Abhay Gupta's current Naukri profile and updated CV. Instrument entries are deliberately labeled as core/current or profile-listed where appropriate, rather than implying unsupported hands-on depth.
