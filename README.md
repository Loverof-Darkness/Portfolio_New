# Abhay Gupta — Scientific Portfolio

Futuristic AMOLED-black personal portfolio for Abhay Gupta, Research Scientist — Analytical Research & Development.

## Design
- Reference-inspired scientific HUD interface
- Pure AMOLED black background
- Interactive chemical-structure field
- Mouse-proximity molecular glow
- Responsive fixed navigation
- Interactive scientific instrument cards and diagrams
- Research, experience, education, publication and certification sections

## Deployment
This is a static single-page site and can be deployed directly to GitHub Pages or Cloudflare Pages.
